# 🍽️ 餐厅点餐与评价系统

餐厅点餐与评价系统，基于 **Spring Boot + Vue 3 + MySQL** 开发，面向校园餐厅小型经营场景，实现菜品浏览、点餐车下单、订单管理、评价打分、商家后台管理，并集成 **AI 智能点餐推荐、菜品文案生成、评论情感分析、经营数据分析、智能客服问答** 五大 AI 功能模块。

---

## 📋 项目简介

- **业务场景**：校园食堂 / 小型餐饮店线上点餐
- **核心流程**：浏览菜品 → 加入点餐车 → 提交订单 → 商家处理 → 用户评价 → AI 情感分析
- **用户角色**：普通用户（就餐顾客）+ 管理员（餐厅商家），双角色权限隔离
- **AI 功能**：5 大 AI 模块深度融入业务，不做孤立聊天框

## 📦 启动步骤

### 1. 数据库初始化

```bash
# 登录 MySQL，执行初始化脚本
mysql -u root -p < database/init.sql
```

脚本会自动创建 `restaurant_db` 数据库、8 张业务表，并插入测试数据。

### 2. 后端启动

```bash
cd backend

# 修改数据库连接配置
# 编辑 src/main/resources/application.yml
# spring.datasource.username 和 spring.datasource.password 改为你的 MySQL 账号密码

# 启动
mvn spring-boot:run
```

后端启动后访问：`http://localhost:8080`

### 3. 前端启动

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端启动后访问：`http://localhost:5173`

## 🤖 AI 功能说明

| AI 功能 | 调用方 | 说明 |
|---------|--------|------|
| 🧠 智能点餐推荐 | 用户 | 输入预算/口味/人数 → AI 推荐菜品组合，可一键加购 |
| 📝 菜品描述生成 | 管理员 | 输入菜名/食材 → AI 生成诱人介绍文案，可编辑保存 |
| 💬 评论情感分析 | 系统自动 | 用户提交评价 → AI 分析好评/中评/差评 + 提取关键词 |
| 📊 经营数据分析 | 管理员 | 聚合订单/菜品数据 → AI 生成经营建议报告 |
| 🤖 智能客服 | 用户 | 右下角悬浮客服，回答营业时间/退单/支付等常见问题 |

**AI 实现说明**：
- 支持真实大模型 API 调用（配置 `application.yml` 中的 `ai.api.key`）
- **未配置 API Key 时自动使用模拟模式**，内置规则可确保验收演示不依赖外部 API
- AI 调用记录自动存入 `ai_record` 表

## 📝 开发注意

1. **密码加密**：用户密码使用 BCrypt 加密存储
2. **订单快照**：下单时快照菜品价格和名称到 `order_item` 表，防止后续菜品价格修改影响历史订单
3. **库存扣减**：下单时扣减库存，取消订单时恢复库存
4. **重复评价拦截**：同一订单只允许评价一次
5. **AI 降级**：AI 接口调用失败不影响主业务（评价提交、菜品保存等）
6. **跨域配置**：后端已配置 CORS，前端开发服务器已配置代理
